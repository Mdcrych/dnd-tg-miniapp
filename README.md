# D&D Character Builder — Telegram Mini App

Telegram Mini App для создания персонажей D&D 5e с бросками кубиков и валидацией билда.

## Функции
- 🎲 Бросок кубиков (d4, d6, d8, d10, d12, d20, d100)
- 🧙 Создание персонажа: раса, класс, характеристики
- ✅ Валидация билда по правилам D&D 5e
- 📊 Подсчёт модификаторов характеристик

## Запуск
```bash
npm install
npm run dev
```

## Деплой
Откройте `index.html` через любой статический хостинг (GitHub Pages, Vercel и т.д.).
Припишите URL в BotFather → Web App URL.
