# Cyberpunk Character Builder — Telegram Mini App

Telegram Mini App для создания персонажей по системе **Cyberpunk Rulebook v0.5**.

## Механики

- **6 характеристик**: STR, DEX, INT, WIL, PER, TEC (значения 1–5, модификаторы −2…+2)
- **Point Buy**: 6 очков, старт на 3, максимум двух на 5
- **23 навыка** с уровнями: Необучен / Обучен / Эксперт / Мастер
- **Старт**: 5 Обучен + 1 Эксперт (Мастер недоступен)
- **Производные параметры**: HP, STRESS, DEF, HUMANITY, IMPLANT LIMIT
- **Происхождения** и **пакеты подготовки** (10 штук × 2)

## Проверки характеристик (popup)

Нажмите на любой блок характеристики — откроется выдвижное окно:
- Выбор DC (8 / 10 / 13 / 16 / 19 / 22)
- Выбор уровня навыка (+0 / +2 / +4 / +6)
- Режим: Обычный / Преимущество (2d20 лучший) / Помеха (2d20 худший)
- Результат: Успех / Успех с ценой (±2) / Провал / Крит
- Хаптик-фидбек в Telegram

## Деплой

```bash
# Локально
npx serve .

# GitHub Pages → Settings → Pages → Branch: main
# URL передать в BotFather → /newapp
```

## Валидация билда

Кнопка «Сохранить» заблокирована, если:
- Более 2 характеристик на значении 5
- Потрачено больше 6 очков
- Более 5 навыков Обучен
- Более 1 навыка Эксперт
- Взят уровень Мастер при создании
